# 出典と追加した内容

本書は、作成済みのチェックリストの回答例と、スキル習熟度の定義を統合したものです。社内で運用するために、目的、評価手順、判定のルール、改善への接続、記録書式を追加しています。

[スキル定義](../skills/index.md)は、提示された28スキルのID・分類・前提と、各スキルのLv0〜Lv4を収録しています。[チームチェックリスト](../checklists/index.md)は、提示されたチェックリストの100項目を原順で収録しています。各項目のリンクは原文に含まれる参照先です。本書で追加した判定方法や回答例を、リンク先が定める公式の評価方法として扱いません。

PRはPull Requestを指します。GitLabを使用する場合は、MR（Merge Request）に読み替えてください。

## 文書の由来

- 利用者が提示したフロントエンドの28スキル・4分類を基にしています。
- チェック項目の原文とURLは、利用者が提示した100項目を継承しています。各項目の「原文の参照先」から個別の出典を確認できます。
- 習熟度の定義、望ましい回答例、評価手順、改善方法、記録書式は本ガイドで追加した内容です。
- 参照先の更新を自動反映する仕組みではありません。変更時は原文との違いを確認し、改訂履歴へ記載します。
