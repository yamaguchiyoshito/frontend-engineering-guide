# 改訂履歴

## 1.2.5 — 2026年9月27日

- 28スキルページから「評価を記録する」の節と、判定方法への案内文を削除。各ページはスキルID、領域、評価対象または前提、Lv1〜Lv4の要約、Lv0〜Lv4の定義だけで構成。
- 到達状態、チェック項目、回答例の変更なし。

## 1.2.4 — 2026年9月27日

- チームチェックリストの各項目から、本書独自の「望ましい原文への回答：TRUE／FALSE」の行を削除。回答の方法は原典に従い、本書の追加は回答例と改善管理用の判定のみに整理。
- 到達状態、チェック項目、回答例の変更なし。

## 1.2.3 — 2026年9月27日

- チームチェックリストの原典が一般社団法人日本CTO協会「Webフロントエンド版DX Criteria（v202402）」であることを、ホーム、チェックリスト一覧、25の小テーマの各ページ、サイトのフッター、単一Markdownの冒頭、READMEに明示。
- 出典ページを改訂。原典のライセンス（CC BY-SA 4.0）と本書で加えた変更を記載。
- リポジトリ全体をCC BY-SA 4.0で提供することを明記し、`LICENSE` にライセンス全文を追加。
- チームチェックリストの分類と名称を原典の5つの大テーマ・25の小テーマ・4つの観点に変更し、各ページと項目に原典IDと観点名を併記。原典の補足説明（37項目）を収録。本書独自の判定方法の説明を削除し、原典の概要・ポリシーと構造・使い方へのリンクに置き換え。
- 到達状態、チェック項目、望ましい判定の変更なし。

## 1.2.2 — 2026年9月27日

- 公開方式を、リリースタグのpushから `main` へのマージへ変更。PRでは検査のみを行い、マージを契機に同じ検査を通して公開。
- タグ検証スクリプトと `test:release` を削除。旧版へ戻す手順をrevertのマージに変更。
- README、ARCHITECTURE、編集・検証・公開手順を新しい方式に更新。到達状態、チェック項目、望ましい判定の変更なし。

## 1.2.1 — 2026年9月27日

- 読みやすさの改善。各ページの説明文（description）を内容に合わせて書き換え、スキル定義とチームチェックで同名のページをブラウザのタブ表示で区別できるように変更。
- 各スキルページの冒頭に、Lv1〜Lv4の到達状態の要約を追加。
- 改善ガイドの関連付け表から、スキル定義とチェックリストの各ページへリンク。
- 基礎領域の一覧の列名を「評価対象」に変更し、説明文を修正。
- PR／MRの表記の注記を全体像ページに追加。到達状態、チェック項目、望ましい判定の変更なし。

## 1.2.0 — 2026年9月27日

- GitHubの公開リポジトリと、一般公開のGitHub Pagesを前提とする構成へ変更。
- 統合文書1.1を76ページに分割。28スキル・140定義・100チェック項目を維持。
- 日本語・スキルID・項目No.の検索、文書ナビゲーションを追加。
- 同じ正本から単一Markdownと4種類の記録書式を生成。
- PR検査、リリースタグによる公開、既存タグの再公開手順を追加。
- 公開対象を基準、空の書式、架空の回答例に統一。到達状態と望ましい判定の変更なし。

## 1.1 — 2026年9月27日

スキルの分類を4つの領域名に統一し、習熟度のLv0〜Lv4と区別できるよう説明・表・見出しを更新。

## 1.0 — 2026年9月27日

スキル定義とチェックリストを統合し、社内評価・改善の手順と書式を追加。
