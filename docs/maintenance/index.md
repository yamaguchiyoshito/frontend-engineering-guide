# 運用・改訂

このガイドは一般公開の基準集です。公開するものは共通定義、使い方、空の記録書式、架空の回答・記入例です。実際の評価記録は所属組織の管理先に保管します。

## 定義を変更するとき

スキルID、習熟度の定義、チェック項目の解釈を変更するときは、変更理由、対象、既存の評価への影響、適用日を記録します。評価基準が変わった場合、以前の判定を自動的に書き換えず、変更点を確認して必要な範囲を再評価します。

スキルの追加や分割を行う場合は、既存IDとの関係を残します。チーム固有の補足は適用範囲を明示し、共通定義と区別します。

## 編集と公開

Markdownの正本はリポジトリの `docs/` にあります。Pull Requestで変更を確認し、検査が通った変更を `main` に統合します。公開用タグ `vX.Y.Z` を作成すると、同じコミットからサイト、単一Markdown、記録書式が生成されます。
