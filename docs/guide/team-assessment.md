# チームの取り組みを確認する

## チェックリストの位置付け

[チームチェックリスト](../checklists/index.md)は、開発環境、設計、品質、CI/CD、運用、学習、連携などの100項目で構成されています。原文は一般社団法人日本CTO協会の[Webフロントエンド版DX Criteria](https://dxcriteria.cto-a.org/frontend)で、原典のチェック項目とリンクを維持し、それぞれに望ましい判定と回答例を付けています。

**回答例は、望ましい状態を実現した場合の記入例です。自社や対象チームで実施済みであることを示すものではありません。** 実際の回答では、実態、対象範囲、頻度、根拠資料を記載します。回答例にある月次・四半期などの頻度は、原文を具体化した運用案です。

## 原文への回答と改善上の判定

100項目のうち75項目は、望ましい取り組みを実施しているかを問います。これらは原文への回答がTRUEとなる状態を目指します。残る25項目は問題の発生を問うため、FALSEとなる状態を目指します。

| 原文の種類 | 例 | 望ましい回答 |
| :--- | :--- | :---: |
| 取り組みの実施を問う | 静的型付け言語、フォーマッター、リンターを導入している。 | TRUE |
| 問題の発生を問う | 機密情報がソースコードにハードコーディングされている。 | FALSE |

改善の管理には、原文へのTRUE／FALSEとは別に、次の判定を記録します。

| 判定 | 使用する条件 | 次に行うこと |
| :--- | :--- | :--- |
| 達成 | 対象範囲で、望ましい状態を満たす証拠を確認できた。 | 運用を継続し、次回の確認時期を決めます。 |
| 一部達成 | 対象範囲や条件の一部で実施を確認できるが、全体としては満たしていない。 | 不足する条件と対象を明記し、改善を計画します。 |
| 未達 | 望ましい取り組みを実施していない、または問題の発生を確認した。 | 影響と原因を確認し、対応の優先順位を決めます。 |
| 未評価 | 判断に必要な情報や証拠を確認できていない。 | 情報の取得先と確認担当者を決めます。 |
| 対象外 | 項目の適用条件に該当しない。 | 対象外とする理由と、見直しの契機を記録します。 |

部分的な実施をTRUEとして報告しないようにします。原文に複数の条件がある場合は、そのすべてを満たしているかを確認します。問題の発生を問う項目では、対象範囲内でその問題を確認した場合、原文への回答はTRUE、改善上の判定は未達です。

原典のアセスメントにある「but」列は、定義が示されていないため本書では使用しません。一部達成・未評価・対象外を分けて記録します。原文への回答を確定できない場合は保留とし、その理由を記載します。

## 確認する範囲と証拠

最初にチーム、リポジトリ、環境、対象期間を決めます。ローカルでの実行結果を本番環境の運用実績として扱うなど、範囲の異なる証拠を混同しないようにします。

| 確認すること | 証拠の例 |
| :--- | :--- |
| 設定が存在するか | リポジトリ内の設定、権限設定、設計書、手順書 |
| 実行されているか | CIの実行履歴、監視結果、更新PR／MR、レビュー記録 |
| 定期的に行われているか | 対象期間内の複数回の記録、予定と実績、担当者の記録 |
| 結果が改善につながっているか | 改善イシュー、変更内容、対応後の計測、振り返り記録 |

設定が存在するだけでは、継続的な運用を求める項目を達成としません。また、問題が報告されていないだけでは、問題が起きていないと断定できません。確認方法と対象期間を残します。

## 確認の手順

1. **範囲を決めます。** 対象チーム、システム、環境、期間、確認責任者を記録します。
2. **適用条件を確認します。** 100項目について対象か対象外かを整理します。例えば一般公開URLに関する項目は、対象サービスの公開範囲を確認します。
3. **証拠を集めます。** 設定、実行記録、設計書、運用記録を参照し、関係者に不足情報を確認します。
4. **現状の文面を書きます。** 回答例を参考に、実施内容、未実施の内容、対象範囲、頻度を事実に合わせて記載します。
5. **判定を付けます。** 原文への回答と、達成・一部達成・未達・未評価・対象外を区別して記録します。
6. **改善対象を選びます。** 未達や一部達成の影響を比較し、担当者、期限、完了条件を設定します。未評価は確認作業として管理します。

集計する場合は、対象項目数と各判定の件数を併記します。未評価を達成扱いにせず、対象外の項目を含む固定の100点満点でチームを順位付けしません。
