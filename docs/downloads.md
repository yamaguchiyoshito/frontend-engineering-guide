# ダウンロード

サイトと同じ文書から生成したMarkdownを取得できます。保存したファイルには版と生成元コミットを記録しています。

<Downloads />

## 使い方

単一Markdownは、使い方、要素技術、チームチェック、書式、記入例、運用の順に読めます。文書内の参照リンクは同じファイル内の見出しに変換しています。

記録書式のZIPには4種類の空のMarkdownが含まれます。記入後のファイルは所属組織が指定する管理先に保管してください。
