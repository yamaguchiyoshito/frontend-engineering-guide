# 習熟度マトリクス

31の要素技術のLv0〜Lv4、155の到達状態を一枚で見渡すための表です。行は[要素技術](index.md)を領域の順に、列は習熟度を並べています。表の中は縦横にスクロールでき、見出し行と要素技術の列は固定されます。

各要素技術の前提、はじめの一歩、参考リンクは要素技術名のリンク先で確認してください。判定のルール（支援の有無、根拠、未評価の扱い）は[個人の評価方法](../guide/individual-assessment.md)を参照してください。
