# 基礎領域

この領域に含まれる5つの要素技術を示します。「評価対象」は、各要素技術で習熟度を確認する主な範囲です。他の領域の要素技術は、これらを前提知識としています。

<!-- catalog:start -->

| ID | 要素技術 | 評価対象 |
| :--- | :--- | :--- |
| `web.basic` | [Web基礎](web.basic.md) | HTTP、URL、ブラウザ、Cookie、キャッシュ |
| `html.basic` | [HTML](html.basic.md) | 文書構造、フォーム、基本要素 |
| `css.basic` | [CSS](css.basic.md) | セレクタ、ボックスモデル、レイアウト |
| `javascript.basic` | [JavaScript](javascript.basic.md) | 構文、関数、オブジェクト、配列 |
| `git.basic` | [Git](git.basic.md) | branch、commit、merge、rebase |
