# HTML

**要素技術ID：** `html.basic`  
**領域：** [基礎領域](index.md)  
**評価対象：** 文書構造、フォーム、基本要素

<!-- terms:start -->

**前提となる用語：** [HTML](../../guide/glossary.md#html)、[ブラウザ](../../guide/glossary.md#ブラウザ)、[フォーム](../../guide/glossary.md#フォーム)、[開発者ツール](../../guide/glossary.md#開発者ツール)

<!-- terms:end -->

HTMLで文書の構造とフォームを組み立てる要素技術です。要素の役割を理解して適切な構造を実装し、リンク、ボタン、フォーム送信の基本動作を自分で確認・修正できるかを評価します。

::: start
MDNの「HTMLの学習」に沿って、見出し、段落、リンク、画像、リストだけの短いページを一つ作り、ブラウザで表示します。フォームの入力欄と送信ボタンまで置き、W3Cの検証サービスで指摘された誤りを直せれば、Lv1の入口です。まず読む：[MDN：HTMLの学習](https://developer.mozilla.org/ja/docs/Learn_web_development/Core/Structuring_content)
:::

## Lv0

要素・属性・入れ子の基本を説明できず、簡単な文書やフォームの作成にも手順ごとの指示が必要である。

## Lv1

例を参考に、見出し、段落、リンク、画像、リスト、入力欄を持つページを作成し、ブラウザで表示と操作を確認できる。

## Lv2

要件から基本要素を選び、適切な文書構造、ラベル付きフォーム、リンクやボタンの動作を実装できる。構文上の問題と基本操作を自分で確認・修正できる。

## Lv3

複雑なフォームや動的に生成される文書で、要素の誤用、入れ子、フォーム送信、フォーカスなどの問題を特定できる。ブラウザの標準動作を踏まえて実装をレビュー・改善できる。

## Lv4

HTMLの実装規約、フォームの共通パターン、確認項目を整備し、テンプレートや自動検査として利用できる状態にできる。チームでの利用結果から修正漏れや手戻りの減少を確認できる。
