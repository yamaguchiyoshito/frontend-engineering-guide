# 品質・高度化領域

この領域に含まれる8つの要素技術を示します。前提知識は学習の目安であり、同じ習熟度への到達を一律に要求するものではありません。

<!-- catalog:start -->

| ID | 要素技術 | 主な前提 |
| :--- | :--- | :--- |
| `test.unit` | [単体テスト](test.unit.md) | JavaScript、TypeScript |
| `test.component` | [コンポーネントテスト](test.component.md) | React |
| `test.integration` | [結合テスト](test.integration.md) | React、API連携 |
| `test.e2e` | [E2Eテスト](test.e2e.md) | フォーム、API連携 |
| `test.design` | [テスト設計](test.design.md) | 各テスト実装 |
| `web.performance` | [Webパフォーマンス](web.performance.md) | HTML、CSS、JavaScript、React |
| `web.security` | [Webセキュリティ](web.security.md) | Web基礎、JavaScript、API連携 |
| `frontend.quality` | [フロントエンド品質保証](frontend.quality.md) | テスト設計、性能、セキュリティ |

<!-- catalog:end -->
