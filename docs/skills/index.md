# スキル定義

スキルは4つの領域に分類します。領域は資格の序列ではなく、担当業務と前提知識に応じて組み合わせるためのまとまりです。

各スキルにはLv0〜Lv4の到達状態を定義しています。根拠が足りない場合の「未評価」はLv0と区別します。[個人の評価方法](../guide/individual-assessment.md)と併せて確認してください。
