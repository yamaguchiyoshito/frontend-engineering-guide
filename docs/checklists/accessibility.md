# アクセシビリティ

**原典：** [Webフロントエンド版DX Criteria](https://dxcriteria.cto-a.org/frontend)（一般社団法人日本CTO協会、CC BY-SA 4.0）  
**大テーマ：** 2. ユーザー体験を支える品質  
**小テーマ：** 2-2 アクセシビリティ（本書の項目No.025〜028）

## C025

**チェック項目 No.025（原典 2-2-1：メトリクスの計測）**

Lighthouseやaxe-coreなどを利用した自動アクセシビリティテストを日常的（日ごと〜週ごと）に実施している。

### 望ましい回答例

主要画面と共通UIコンポーネントに対する自動アクセシビリティ検査を、PRごとおよび週次に実行しています。通常表示に加え、入力エラーやモーダル表示などの状態も検査対象にしています。検出結果をCIに保存し、必須基準への違反は修正してからマージしています。

[原文の参照先](https://dxcriteria.cto-a.org/824b5fb881824f7682b818df9db34374)

## C026

**チェック項目 No.026（原典 2-2-2：学習と改善）**

Webアクセシビリティについて目指す品質基準を開発のガイドラインとして定めている。

**原典の補足**

自分たちの事業において、どの程度の基準を満たすようにWebアクセシビリティを整備するか言語化しておくことが重要である。

具体的にはJIS X 8341-3:2016 か WCAG (Web Content Accessibility Guidelines) の各レベル A/AA/AAAを目安にできる。方針策定および対外的な基準の掲出に際してはウェブアクセシビリティ基盤委員会が公開しているウェブアクセシビリティ方針策定ガイドラインやデジタル庁のウェブアクセシビリティ導入ガイドブックを参考にするとよい。

### 望ましい回答例

アクセシビリティの対象範囲、参照する規格の版、目標とする適合レベルをガイドラインに明記しています。キーボード操作、フォーカス、ラベル、色の識別、エラー通知などの実装・確認方法を具体化しています。例外の扱いと受け入れ条件を定め、設計・実装・レビューで共通して使用しています。

[原文の参照先](https://dxcriteria.cto-a.org/f317091fc6df410299a1c4dca693c514)

## C027

**チェック項目 No.027（原典 2-2-3：プラクティス）**

開発プロセスの中で人による視認性、操作性、情報構造などのレビューを行っている。

**原典の補足**

Webアクセシビリティの課題は自動テストで検出できるものばかりではない。開発プロセスの各段階において手動テストによるチェックを挟むことでアクセシビリティの確実性が高まる。

WCAGはもちろんAndroidなど他プラットフォームのドキュメントでも手動テストによるアクセシビリティチェックの併用を推奨している。

### 望ましい回答例

設計レビューとリリース前の確認に、人によるアクセシビリティレビューを組み込んでいます。キーボードのみの操作、拡大表示、文字や配色の視認性、見出し構造、読み上げ時の理解しやすさを確認しています。指摘を記録し、修正後の再確認まで担当者を決めて追跡しています。

[原文の参照先](https://dxcriteria.cto-a.org/5e2a546c7ee94a84b0695620fef1ef11)

## C028

**チェック項目 No.028（原典 2-2-4：アンチパターン）**

HTMLのフォーム要素やナビゲーション要素を代替するUIパーツを開発する中で、ブラウザが提供する標準的な操作性が失われてしまっている。

**原典の補足**

通常、標準的なフォーム要素を使用することでキーボード操作等のアクセシビリティは担保されるが、div要素等を多用したオリジナルのUIを開発する場合はフォーカスや選択などのサポートを独自に実装する必要がある。

見た目はオリジナルでも内部的に標準のHTML要素を活かすことで、独自実装をせずにアクセシビリティを維持できる場合がある。またOSSとして公開されているUIコンポーネントライブラリの多くはアクセシビリティに配慮した実装がされているので、それらをカスタムして使用するのも良い方法である。

### 望ましい回答例

独自UIを導入しても、キーボード操作、フォーカス移動、フォーム送信、リンク操作などの標準的な操作性を損なっていません。可能な限り意味に合ったHTML要素を使用し、独自実装が必要な場合は同等の操作性を実装しています。対応するブラウザと支援技術で動作を確認しています。

[原文の参照先](https://dxcriteria.cto-a.org/6676a4cd96d048c2aeea40c46982b8e5)
