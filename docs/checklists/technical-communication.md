# 技術発信の継続

**項目No.：097〜100**

回答例は望ましい状態を示す架空の文面です。[判定方法](../guide/team-assessment.md)と[記録書式](../templates/team-assessment.md)を使い、実態と根拠を記録してください。

## C097

**チェック項目 No.097**

チーム全体で発信の方針を定め、それに基づいて定期的（月ごと〜半年ごと）に発信数やインプレッション関連指標をモニタリングしている。

**望ましい原文への回答：TRUE**

原文にある取り組みを実施している状態を目指します。

### 望ましい回答例

発信の目的、対象読者、テーマ、チャネル、公開頻度をチームで定めています。月次で発信数、閲覧数、インプレッションなどを確認し、目的に応じて問い合わせや採用応募などとの関係も評価しています。結果を基に企画と発信方法を見直し、担当者と次の実施時期を決めています。

[原文の参照先](https://dxcriteria.cto-a.org/a795f6d9cea2461198ed24686b7641f9)

## C098

**チェック項目 No.098**

発信内容についてレビュープロセスを設けて社内での議論や学習を促している。

**望ましい原文への回答：TRUE**

原文にある取り組みを実施している状態を目指します。

### 望ましい回答例

発信内容には技術的な正確性、読み手の理解、公開可能な情報かどうかを確認するレビュープロセスを設けています。執筆者とレビュアーを決め、指摘と修正理由を記録しています。レビューで得た知見はチーム内に共有し、発信を実務の振り返りと学習の機会にしています。

[原文の参照先](https://dxcriteria.cto-a.org/74080a0af5104c80871932e7ba299878)

## C099

**チェック項目 No.099**

テックブログや勉強会の開催、外部イベントへの登壇など複数チャネルにおける発信のチーム内実績がある。

**望ましい原文への回答：TRUE**

原文にある取り組みを実施している状態を目指します。

### 望ましい回答例

直近1年間に、テックブログ、勉強会、外部イベントなど複数のチャネルでチームとして発信した実績があります。公開URL、開催日、担当者、対象読者を一覧化し、資料を再利用できるようにしています。発信後の反応と得られた知見を共有し、次の企画に反映しています。

[原文の参照先](https://dxcriteria.cto-a.org/2316c5f0e3d44877aa14c0749f42d62b)

## C100

**チェック項目 No.100**

外部発信の活動が特定の個人に依存しており、チーム全体で持続可能な取り組みになっていない。

**望ましい原文への回答：FALSE**

原文にある問題が発生していない状態を目指します。

### 望ましい回答例

発信を特定の個人の自主活動だけに依存させず、企画、執筆、レビュー、公開の役割と作業時間をチームで確保しています。発表者を育成するため、共同執筆や共同登壇、テンプレート、レビュー支援を用意しています。四半期ごとに担当の偏りと継続状況を確認し、無理なく継続できる計画へ見直しています。

[原文の参照先](https://dxcriteria.cto-a.org/fac5f7f0244f4e4699102ee484b644fb)
