# チームチェックリスト

本ページの100項目は、一般社団法人日本CTO協会の[Webフロントエンド版DX Criteria（v202402）](https://dxcriteria.cto-a.org/frontend)（CC BY-SA 4.0）です。分類（5つの大テーマ × 5つの小テーマ × 4つの観点）、項目の文面、回答の方法は出典に従います。本書では独自の判定方法を説明せず、次の出典ページを参照してください。

- [Webフロントエンド版DX Criteriaの概要](https://dxcriteria.cto-a.org/e29172142f0f4eacbc17f3d94c8160d0)
- [ポリシーと構造](https://dxcriteria.cto-a.org/90a7445d540148408343e83f4cbbecac)
- [使い方](https://dxcriteria.cto-a.org/db7e371398c2464792dc25d79e573ba1)

出典では小テーマごとに、メトリクスの計測、学習と改善、プラクティス、アンチパターンの4つの観点から項目が定義されています。本書は出典の項目文と補足説明をそのまま収録し、観点名を各項目に併記しています。

100項目を1ページで回答・記入するには、[チームチェック回答シート](assessment.md)を使ってください。小テーマごとのページと同じ記録を共有します。

本書で加えたのは、架空の「望ましい回答例」、各ページ冒頭の「前提となる用語」（[用語集](../guide/glossary.md)への案内）、末尾の「参考リンク」、[チームの確認書式](../templates/team-assessment.md)です。詳細は[出典と追加した内容](../maintenance/sources.md)を参照してください。
